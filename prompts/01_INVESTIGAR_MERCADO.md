# Prompt 01 — EVALUACIÓN DEL NICHO

Actúa como analista de producto y SEO. Antes de crear decenas de páginas, compara al menos 6 áreas posibles de herramientas web con ingresos de display ads: energía doméstica, hogar/bricolaje, texto/archivos, productividad estudiantil, viajes/logística y entretenimiento/hobbies. Selecciona hasta 3 subnichos por área.

Para cada área investiga mediante fuentes públicas accesibles: intención y demanda de búsqueda, dificultad competitiva visible, originalidad posible mediante calculadoras, mercados/países, estacionalidad, mantenimiento, sensibilidad YMYL, monetización ads-only y coste operativo. Usa fuentes, fechas y URLs; separa volumen verificado de aproximaciones. No inventes Keyword Planner/Ahrefs/Semrush, volúmenes ni RPM. Si no hay acceso a esas herramientas, crea una tabla de indicadores proxy y una lista de datos que el dueño deberá obtener.

Construye una rúbrica ponderada (demanda 25%, diferenciación 25%, competencia alcanzable 20%, monetización 15%, coste/riesgo 15%). Considera como hipótesis inicial herramientas energéticas, pero recomienda cambiarla si la evidencia favorece otra. Entrega docs/investigacion-mercado.md, docs/decision-nicho.md, 20 posibles keywords por intención como hipótesis y una secuencia de validación de 4 semanas. No generes artículos ni avances al despliegue hasta documentar conclusiones.
