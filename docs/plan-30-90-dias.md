# Plan 30/90 días

Borrador; fecha base 2026-10-13. Secuencia orientativa, no compromiso de tráfico, rentabilidad o publicación. Fuente de estado única: backlog.md.

- Días 1–7: investigación documental, exportaciones de demanda, comparación energía/hogar, PRD y decisión provisional. Entrevistas y exportaciones requieren participación del propietario.
- Días 8–14: pruebas privadas de comprensión y arquitectura del MVP, prompt 02. Revisar el nicho si faltan huecos. No generar contenido público.
- Días 15–21: prompt 03, cinco calculadoras, fórmulas y tests unitarios/smoke. Documentar anualización y supuestos.
- Días 22–30: prompts 04, 05 y 06 en orden: borradores editoriales, bloqueo de publicidad/analítica, CI y preparación de Pages. Revisión de accesibilidad, SEO y seguridad; PRs con resultados. No conectar producción automáticamente.
- Días 31–60: corregir revisión editorial y jurídica, confirmar titular/contacto/dominio, auditoría prompt 09. Lanzar solo si hay autorización, aprobación de contenido y controles completos. Solicitud AdSense no equivale a aceptación.
- Días 61–90: si hubo lanzamiento, estudiar Search Console y datos consentidos con prompt 08. Revisar utilidad, errores, consultas y costes. Si no hubo lanzamiento, completar gates; no fabricar métricas. Decidir ampliar, mantener o pivotar y registrar evidencia.

La auditoría semanal del prompt 07 se podrá ejecutar manualmente. No programar auditorías de API facturable ni activar claves sin autorización. Los datos reales prevalecen sobre este calendario.
